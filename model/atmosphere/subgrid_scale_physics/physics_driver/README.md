# icon4py-atmosphere-physics-driver

The physics driver (`PhysicsDriver`) for ICON4Py, modelled on ICON-MPIM's AES physics interface (`aes_phy_main`).

`PhysicsDriver` and its processes (`MuphysComponent`, a `PhysicsComponent` under a `ProcessTimeControl`) are typed components; see [ADR 0004](../../../../docs/development/ADRs/0004_typed_states_and_components.md).
