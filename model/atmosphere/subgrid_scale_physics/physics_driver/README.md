# icon4py-atmosphere-physics-driver

The physics driver (`PhysicsDriver`) and its processes (`PhysicsProcess`, `ProcessTimeControl`) for ICON4Py, modelled on ICON-MPIM's AES physics interface (`aes_phy_main`).

`PhysicsDriver` and its processes (`MuphysComponent`, `TmxComponent`) are typed components; see `icon4py/model/common/components/README.md` in `icon4py-common`.
